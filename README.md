# EnglishTrainer

Android-приложение для изучения английских слов и выражений.

## Возможности

- Изучение английских слов.
- Американское и британское произношение.
- Прослушивание слов и фраз.
- Тренировка перевода.
- Проверка знаний с помощью тестов.
- Работа без подключения к интернету.
- Современный простой интерфейс.

## Цель проекта

Создать удобное мобильное приложение для самостоятельного изучения английского языка.

## Платформа

Android

## Язык интерфейса

Русский
